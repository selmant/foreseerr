First alpha of **Foreseerr for Jellyfin**, a third-party plugin that runs Foreseerr inside Jellyfin and signs users in with their Jellyfin account.

> [!WARNING]
> **Alpha, in active development.** Anything can change between releases: settings, data, URLs, and behavior. There is **no backward compatibility** between plugin versions, and no upgrade path is promised. If an update misbehaves, uninstall the plugin, delete `plugins/configurations/Foreseerr` in Jellyfin's data folder, and install again. Do not rely on it for data you cannot recreate.

## Install

1. Jellyfin → Dashboard → Plugins → Repositories → add
   `https://raw.githubusercontent.com/selmant/foreseerr/jellyfin-plugin-repository/manifest.json`
2. Install **Foreseerr** from the catalog and restart Jellyfin. Jellyfin 10.11 and 12 each get their own build from the same release.
3. Open Foreseerr as a Jellyfin administrator first; that account becomes the Foreseerr owner.
4. Optional: install [File Transformation](https://github.com/IAmParadox27/jellyfin-plugin-file-transformation) for a Foreseerr button in the Jellyfin Web header.

Manual install: extract `foreseerr-jellyfin-10.11.zip` or `foreseerr-jellyfin-12.zip` into Jellyfin's `plugins/Foreseerr/` folder and restart Jellyfin.

## What's included

- Foreseerr served at `<Jellyfin>/Foreseerr/`, including Jellyfin on a sub-path, with Jellyfin sign-in and no separate password.
- Jellyfin address, API key, libraries, locale, and first administrator imported automatically; the setup wizard is skipped.
- Jellyfin administrators are Foreseerr admins.
- Foreseerr adapts to running inside Jellyfin: **Back to Jellyfin** instead of Sign Out, Jellyfin connection settings managed by the plugin, and no local users, passwords, or web push.
- Users Foreseerr refuses see why (for example, when new sign-ins are off).
- Plugin page in the Jellyfin dashboard with status, a direct link, and the public Jellyfin URL for notification links.

## Requirements and limits

- Jellyfin 10.11 or newer, on Linux x64, Linux arm64, or Windows x64.
- Jellyfin Web in a browser. The official mobile and TV apps cannot open Foreseerr.
- Behind a reverse proxy, forward `/Foreseerr` and `/ForeseerrPlugin`, and add the proxy to Jellyfin's Known Proxies.

## Known issues

- On the first start, Foreseerr downloads its anime mapping data and can stop responding for a minute or two while it stores it.
- Not yet tested behind a real TLS-terminating reverse proxy.
