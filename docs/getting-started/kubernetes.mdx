# Kubernetes
:::warning
This method is not recommended for most users. It is intended for advanced users who are using Kubernetes.
:::

:::info
All official Foreseerr charts are cryptographically signed and include a verified [Software Bill of Materials (SBOM)](https://cyclonedx.org/).

To confirm that the chart you are using is authentic and unmodified, please refer to the [Verifying Signed Artifacts](/using-seerr/advanced/verifying-signed-artifacts#verifying-signed-helm-charts) guide.
:::

## Installation
```console
helm install foreseerr oci://ghcr.io/selmant/foreseerr/foreseerr-chart
```
Helm values can be found in the Foreseerr repository under [charts/foreseerr-chart/README.md](https://github.com/selmant/foreseerr/tree/develop/charts/foreseerr-chart).

Verify the signature with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) (replace [tag], with the TAG you want to verify) :
```console
cosign verify ghcr.io/selmant/foreseerr/foreseerr-chart:[tag] --certificate-identity=https://github.com/selmant/foreseerr/.github/workflows/helm.yml@refs/heads/develop --certificate-oidc-issuer=https://token.actions.githubusercontent.com
```
