# Build from Source (Advanced)
:::warning
This method is not recommended for most users. It is intended for advanced users who are familiar with managing their own server infrastructure.

Refer to [Configuring Databases](/extending-seerr/database-config#postgresql-options) for details on how to configure your database.
:::

import TabItem from '@theme/TabItem';

### Prerequisites
    - [Bun 1.4+](https://bun.sh/) (`>=1.4.0`) to build the web app
    - [Rust](https://rustup.rs/) through `rustup`, plus a C toolchain (`build-essential` on Debian/Ubuntu, the Xcode command line tools on macOS, the Visual Studio C++ build tools on Windows). The first build installs the Rust version pinned in `backend-rs/rust-toolchain.toml`.
    - [Git](https://git-scm.com/downloads)

:::tip
On Linux x64/arm64 and Windows x64 you can skip the build: every [release](https://github.com/selmant/foreseerr/releases) attaches a ready-to-run server archive. Extract it, then start `foreseerr` (`foreseerr.exe` on Windows) from that directory with `NODE_ENV=production`; the service examples below work the same way with that directory as the working directory.
:::

## Unix (Linux, macOS)
### Installation
1. Assuming you want the working directory to be `/opt/foreseerr`, create the directory and navigate to it:
```bash
sudo mkdir -p /opt/foreseerr && cd /opt/foreseerr
```
2. Clone the Foreseerr repository. Use a release tag for production, or `develop` for the latest unreleased work:
```bash
git clone https://github.com/selmant/foreseerr.git .
git checkout v0.15.0
```
3. Install the web app's dependencies:
```bash
bun install --frozen-lockfile
```
4. Build the web app and the server:
```bash
bun run build
```
5. Start Foreseerr:
```bash
bun run start
```

The server is the single binary `backend-rs/target/release/foreseerr`. It reads `seerr-api.yml`, the web app in `dist/public/` and its `config/` directory from its working directory, so always start it from `/opt/foreseerr` (or set `FORESEERR_APP_ROOT=/opt/foreseerr`).

:::info
You can now access Foreseerr by visiting `http://localhost:5055` in your web browser.
:::

#### Extending the installation
<Tabs groupId="unix-extensions" queryString>
  <TabItem value="linux" label="Linux">
To run Foreseerr as a systemd service:
1. create the environment file at `/etc/foreseerr/foreseerr.conf`:
```bash
## Foreseerr's default port is 5055, if you want to use both, change this.
## specify on which port to listen
PORT=5055

## specify on which interface to listen, by default Foreseerr listens on all interfaces
#HOST=127.0.0.1
```

2. Create the systemd service file at `/etc/systemd/system/foreseerr.service`, using either `sudo systemctl edit --force --full foreseerr` or `sudo nano /etc/systemd/system/foreseerr.service`:
```bash
[Unit]
Description=Foreseerr Service
Wants=network-online.target
After=network-online.target

[Service]
EnvironmentFile=/etc/foreseerr/foreseerr.conf
Environment=NODE_ENV=production
Type=exec
Restart=on-failure
WorkingDirectory=/opt/foreseerr
ExecStart=/opt/foreseerr/backend-rs/target/release/foreseerr

[Install]
WantedBy=multi-user.target
```

3. Enable and start the service:
```bash
sudo systemctl enable foreseerr
sudo systemctl start foreseerr
```
  </TabItem>
  <TabItem value="macos" label="macOS">
To run Foreseerr as a launchd service:
1. Create a launchd plist file at `~/Library/LaunchAgents/com.foreseerr.plist`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.foreseerr</string>
  <key>ProgramArguments</key>
  <array>
    <string>/opt/foreseerr/backend-rs/target/release/foreseerr</string>
  </array>
  <key>WorkingDirectory</key>
  <string>/opt/foreseerr</string>
  <key>EnvironmentVariables</key>
  <dict>
    <key>NODE_ENV</key>
    <string>production</string>
    <key>PORT</key>
    <string>5055</string>
  </dict>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
</dict>
</plist>
```
2. Load the service:
```bash
launchctl load ~/Library/LaunchAgents/com.foreseerr.plist
```
3. Start the service:
```bash
launchctl start com.foreseerr
```
  </TabItem>
  <TabItem value="pm2" label="PM2">
To run Foreseerr as a PM2 service:
1. Install PM2:
```bash
npm install -g pm2
```
2. Start Foreseerr with PM2 from `/opt/foreseerr`:
```bash
NODE_ENV=production pm2 start backend-rs/target/release/foreseerr --name foreseerr --interpreter none
```
3. Save the process list:
```bash
pm2 save
```
4. Ensure PM2 starts on boot:
```bash
pm2 startup
```
**Managing the service**
- To start the service:
```bash
pm2 start foreseerr
```
- To stop the service:
```bash
pm2 stop foreseerr
```
- To restart the service:
```bash
pm2 restart foreseerr
```
- To view the logs:
```bash
pm2 logs foreseerr
```
- To view the status:
```bash
pm2 status foreseerr
```

## Windows
### Installation
1. Assuming you want the working directory to be `C:\foreseerr`, create the directory and navigate to it:
```powershell
mkdir C:\foreseerr
cd C:\foreseerr
```
2. Clone the Foreseerr repository. Use a release tag for production, or `develop` for the latest unreleased work:
```powershell
git clone https://github.com/selmant/foreseerr.git .
git checkout v0.15.0
```
3. Install the web app's dependencies:
```powershell
bun install --frozen-lockfile
```
4. Build the web app and the server:
```powershell
bun run build:web
cd backend-rs; cargo build --release --locked; cd ..
```
5. Start Foreseerr:
```powershell
$env:NODE_ENV = "production"; .\backend-rs\target\release\foreseerr.exe
```

:::info
You can now access Foreseerr by visiting `http://localhost:5055` in your web browser.
:::

#### Extending the installation
<Tabs groupId="windows-extensions" queryString>
  <TabItem value="task-scheduler" label="Task Scheduler">
To run Foreseerr as a bat script:
1. Create a file named `start-foreseerr.bat` in the Foreseerr directory:
```batch
@echo off
cd /d "%~dp0"
set PORT=5055
set NODE_ENV=production
backend-rs\target\release\foreseerr.exe
```
2. Create a task in Task Scheduler:
- Open Task Scheduler
- Click on "Create Basic Task"
- Name the task "Foreseerr"
- Set the trigger to "When the computer starts"
- Set the action to "Start a program"
- Set the program/script to the path of the `start-foreseerr.bat` file
- Set the "Start in" to the Foreseerr directory.
- Click "Finish"

Now, Foreseerr will start when the computer boots up in the background.
  </TabItem>

  <TabItem value="nssm" label="NSSM">
To run Foreseerr as a service:
1. Download the [Non-Sucking Service Manager](https://nssm.cc/download)
2. Install NSSM:
```powershell
nssm install Foreseerr "C:\foreseerr\backend-rs\target\release\foreseerr.exe"
nssm set Foreseerr AppDirectory "C:\foreseerr"
nssm set Foreseerr AppEnvironmentExtra NODE_ENV=production
```
3. Start the service:
```powershell
nssm start Foreseerr
```
4. To ensure the service starts on boot, run the following command:
```powershell
nssm set Foreseerr Start SERVICE_AUTO_START
```

### Updating
To update Foreseerr, navigate to the Foreseerr directory, fetch the tag or branch you want, then rebuild and restart:
```bash
git fetch --tags
git checkout v0.15.0
bun install --frozen-lockfile
bun run build
```
Then restart the process or service you configured above.
